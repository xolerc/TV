# XOLERIC · So'z o'rgatuvchi (TV)

An Uzbek syllable/vocabulary learning app with timer and letter-browsing modes. Covers all Uzbek alphabet letters with words grouped by difficulty (6 steps).

## Features
- Timer mode: auto-advancing word display with configurable speed
- Letter mode: browse words by letter and difficulty step
- Text-to-speech for word pronunciation
- Favorites system with localStorage
- Keyboard navigation (arrows + enter)
- Full-screen toggle

## How to open
Open `index.html` in any modern browser.
